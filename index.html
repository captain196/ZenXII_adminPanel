About us

One school. Three systems. One platform.

ZenXii is a real-time operating system for schools — admin panel for the office, teacher app for the classroom, parent app for the home. Built so the same fact never has to be typed twice.

Our mission

Give every school the operational clarity the best companies enjoy — without losing the warmth of a school day.

Why we built it

We watched school offices juggle 5–10 disconnected tools. ZenXii folds them into one tenanted platform, with role-aware access and real-time sync.

Where we are

Headquartered in Bhopal, India. A small team that listens to schools first and ships second.

Benefits

Designed for how a school actually runs.

01

One source of truth, three lenses

The admin records it, the teacher acts on it, the parent sees it — without anyone re-typing anything.

02

Real-time by default

Built on Firebase. A mark goes in on the teacher's phone and the parent sees it before the school bell.

03

Multi-school ready

A dedicated superadmin layer means you can run a single school or a federation of campuses on the same platform.

04

Role-aware admin, open mobile

Tight RBAC for the admin panel. Teachers and parents get full app access — scope is automatic from their assignments and children.

05

Security in layers

Two-layer status checks, forced password change on reset, refresh-token revocation, rate-limited login, industry-standard hashing.

06

Hierarchical password recovery

No risky self-service OTP — a higher-privileged user resets a lower-privileged one. Recovery stays in the school's trusted chain.

FAQ

Common questions.

Is ZenXii available on iPhone?

The Teacher and Parent apps currently ship on Android. iOS is on the roadmap.

How do parents reset their password?

Through the school office — the principal or school super admin resets it from the admin panel. There is no self-service OTP flow by design; this keeps password recovery in the school's trusted chain.

What happens if a parent has multiple children in the school?

They use one login. The Parent app discovers siblings automatically from the school records.

Does the platform support more than one school per account?

Yes — the Superadmin layer is built for multi-school deployments with per-school plans and isolated data.

Where is the data stored?

On a secure cloud backbone. All school data is scoped to the school's tenant.

Can teachers see or edit each other's classes?

A teacher's data scope is automatically determined by their subject and class assignments. They cannot see classes they are not assigned to.

Is there an API?

Yes — the platform exposes an Auth API and webhook endpoints (payment intent, health check). Custom integrations can be discussed on a per-deployment basis.
